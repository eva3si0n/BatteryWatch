## Что это
⚠️ **Проект на паузе, архивный — с 01.10.2026, по решению владельца.** CI, раннер и новые проверки ему не
заводить; новые возможности — только по прямому слову владельца. Последний выпуск — `v1.3.0`.

Заряд iPhone на Apple Watch: iPhone-приложение (`iPhone/`) шлёт уровень батареи через WatchConnectivity,
watch-приложение (`Watch/`) показывает его, расширение WidgetKit (`Widget/`) даёт компликации четырёх
семейств. Общая модель и хранилище App Group — `Shared/BatteryData.swift`. Swift, проект генерирует
XcodeGen из `project.yml`.

## Где живёт
Нигде не развёрнут. Ставится на устройства из Xcode с личной командой подписи (Personal Team: сборка
живёт 7 дней). Выпуски — GitHub Releases, вручную; CI нет.

## Правила, которые нельзя нарушать
- ⛔ **Репозиторий публичный.** Никаких внутренних адресов, доменов, имён машин, локальных путей,
  идентификаторов устройств и записей хранилищ секретов — ни в коде, ни в доках, ни в сообщениях
  коммитов, ни на скриншотах. Нужен пример — плейсхолдер.
- ⛔ **Версия одна — `MARKETING_VERSION` и `CURRENT_PROJECT_VERSION` в `project.yml`**; Info.plist всех трёх
  целей ссылаются на неё. Разъехавшиеся версии iPhone- и watch-части рвут связь WCSession (исправлено в `v1.2.2`).
- ⛔ **`.xcodeproj` не коммитить** — он генерируется (`xcodegen generate`) и лежит в `.gitignore`.
- ⛔ **Не убирать `.containerBackground(for: .widget)` и `ENABLE_DEBUG_DYLIB=NO`:** без первого
  компликация на настоящих часах молча показывает серый «!», без второго виджет, поставленный мимо
  Xcode, не запускается. В симуляторе оба дефекта не видны.
- Watch-часть ставить схемой `BatteryWatchWatch` из Xcode. Прямой `devicectl install` на часы запускает
  приложение, но может не зарегистрировать его компаньоном iPhone-приложения: процент перестаёт
  обновляться без единой ошибки.
- В симуляторных сборках вшита заглушка 82 % (`#if targetEnvironment(simulator)`): у симулятора нет
  батареи, проверять обновление — только на устройствах.

## Проверки
```bash
xcodegen generate
xcodebuild -project BatteryWatch.xcodeproj -scheme BatteryWatch \
  -destination 'generic/platform=iOS Simulator' build
```

Хуки — `git config core.hooksPath .githooks`: `commit-msg` не пускает чужую атрибуцию, `pre-push` гоняет
общую проверку гигиены документации из `~/bin` (нет скрипта — предупреждает и пропускает).
